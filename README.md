# Project Overview
Research project for CSC 495 at Eastern Kentucky University under the supervision of Dr. Nathan Arnold. Written as an experimentation environment to run core stability experiments on Tiered Coalition Formation Games. For more details, please refer to the written report for this study: [Tiered Coalition Formation Games Empirical Study](Tiered-Coalition-Formation-Games-Empirical-Study.pdf)

# File Navigation
All source code files can be found under src/ktieredcoaltionformationgames with the driver class being KTieredCoalitionFormationGames.java
